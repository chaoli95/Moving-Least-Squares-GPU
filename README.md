# Approximating Implicit Surfaces with Moving Least-Squares on GPU

## Compile

GPU version: 

```
nvcc -o mls -lpthread -I/usr/local/include/eigen3 -I./libigl/include/ mls.cu -lcusolver -lcusparse -std=c++11
```

CPU version:

```
g++ -std=c++11 -lpthread -I/usr/local/include/eigen3 -I./libigl/include/ cpu_mls.cpp -o cpu_mls
```

## Usage

GPU version: 

```
./mls data/sphere.off [sphere_output.off]
```

CPU version:

```
./cpu_mls data/sphere.off [sphere_output.off]
```

For both versions the output file name argument is optional. Please note that export the results to the output file will take longer time. We suggest start testing with sphere.off. If you want to test with other point clouds please read the following section first. 

## Changing parameters

For both versions, you'll need to change the source code and re-compile the program in order to change parameters.

### Changing sampling resolutions: 

GPU: change NX, NY, NZ on line 19-21

CPU: change sampling_resolution on line 15

### Changing weight function radius

GPU: change H on line 33

CPU: change wendlandRadius on line 14

Weight function radius also affect the quality of the output as well as execution time. The following table is the recommanded radius for provided point cloud:

| Input       | weight function radius |
| ----------- | ---------------------- |
| sphere.off  | 1.1                    |
| bunny_7k.off|   0.01                 |
| luigi5k     | 8.0                    |

## Library

We use [libigl](https://libigl.github.io/) mainly for exporting the results. For TA's convenience, we include the necessary files from libigl in the submission. 

## Checking output

We didn't filter the noise generated by the marching cubes so there are some bad results in the output off file. We use [meshlab](https://www.meshlab.net) to visualize the results because it can detect and remove the noisy results. We didn't test the output with other tools.
